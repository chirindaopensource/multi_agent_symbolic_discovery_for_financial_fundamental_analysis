## Key callables, Tasks 1 to 36

This discussion covers the 36 final task orchestrators of `multi_agent_symbolic_discovery_for_financial_fundamental_analysis.ipynb`, `run_task_1` to `run_task_36`, in notebook task order. Python implementation author: **CS Chirinda**. The orchestrators' signatures and documented contracts, the docstrings of the stage callables they compose, and the notebook's declared constants establish behaviour; `latex_context.txt` establishes the methodological standard. Internal helpers (for example `run_iteration_body_task_15` or `run_preflight_task_11`) are accounted for inside their parent task rather than counted as additional callables. The notebook was not executed for this document.

Notation: firm $i$, fiscal quarter $t$, accounting database $\mathcal{X}_t$, look-ahead price $y_{i,t+1}$, perspective $a\in\mathcal{A}=\lbrace\mathrm{earnings},\mathrm{cashflow},\mathrm{asset},\mathrm{growth},\mathrm{quality}\rbrace$, context $C(i,t)=(s(i),r(t))$ of sector and market regime, memory $\mathbf{M}^{(a)}$, learnings $\mathbf{Z}^{(a)}$, and context weights $\tilde{\mathbf{w}}_{C(i,t)}$. Errors are fractions of the actual, and every MAPE is taken over admissible rows only (finite prediction, finite and non-zero actual): $\mathrm{MAPE}=\frac{1}{N}\sum_{r}\frac{|\hat y_r-y_r|}{|y_r|}$. Paper equations are numbered as in `latex_context.txt`: (1) $\tilde f_{C(i,t)}(\hat x_{i,t})\approx y_{i,t+1}$; (2) $\hat y^{(a)}_{i,t+1}=\tilde f^{(a)}(\mathbf{x}^{(a)}_{i,t})$; (3) $\mathcal{L}^{(a)}=\mathrm{MAPE}(\hat y^{(a)}_{i,t+1},y_{i,t+1})$; (4) $\hat y_{i,t+1}=\tilde{\mathbf{w}}_{C(i,t)}^\top\hat{\mathbf{y}}_{i,t+1}$; (5) $\mathcal{L}^{\mathrm{meta}}=\mathrm{MAPE}(\hat y_{i,t+1},y_{i,t+1})$; (6) $L=\lfloor4(T/100)^{2/9}\rfloor$.

Data boundary: the licensed Bloomberg fundamentals and FactSet macro panels are not part of this project. Without them the pipeline runs only in its declared synthetic mode, so manuscript figures below are comparison targets, not reproduced results. Task numbers identify notebook cells, not runtime calls: Task 36 drives Tasks 1–4 and 22–35 directly, Task 22 composes Tasks 5–12, 15, 20 and 21, and Tasks 13, 14 and 16–19 run inside Task 15's discovery loop.

### Task 1 — `run_task_1`

- **Inputs**: `config`, a mapping carrying container and base-image digests, resolved wheel pins and digests, index URL and mirror hash, the expected hardware block, the serving registry, server configuration and smoke record, checkpoint record, licensing block, declared git commit, seed list, UTC timestamp and determinism-sweep scope; `output_dir`.
- **Process**: a validation phase writes nothing: licensing boundary, run identifier from container digest plus configuration hash, five-target seed registry, serving-budget validation, checkpoint reconciliation and a sweep of stochastic call sites. A write phase then emits and verifies the requirements lock, appends provenance and deviation records to the append-only register, and writes the environment manifest atomically.
- **Outputs**: `run_id`, `seed_list`, `config_hash`, `artifacts`, `manifest` (digests, executed and declared commit, platform, wheels, hardware, vLLM, model, probes), `seed_registry`, `deviations`, `warnings`, `executed_probes`, `checkpoint_reconciliation`, `serving_budget`, `determinism_sweep`.
- **Transformation**: declared environment facts become one run identity and a provenance manifest. Docker and vLLM are never invoked; the hardware capture and revision query run, and divergences are registered as deviations rather than overwriting either side.
- **Research role**: pins the Implementation Details: "All LLMs are served locally using vLLM … The model context window is 32,768 tokens; we set a maximum generation length of 16,384 tokens."
- **Equations**: the serving budget that later prompt assembly must respect, with headroom $H$ for a smoke request of $P$ prompt and $G$ generation tokens:

$$
B_{\mathrm{prompt}}=32768-16384=16384,\qquad H=W-(P+G),\qquad W=32768.
$$

- **Implementation distinction**: each of the five seeds (the study declares 11, 23, 41, 67, 101) is delivered to `python_random`, `numpy_random`, `differential_evolution`, `slsqp_x0` and `vllm_sampler`; concurrency is pinned at 32 unless a GPU out-of-memory reduction is registered. These are reproducibility contracts, not paper equations.
- **Failure behaviour**: a non-x86_64 machine, a redistributable raw-data flag, a pin without a wheel digest, a budget mismatch or a checkpoint mismatch halts before any file is written.

### Task 2 — `run_task_2`

- **Inputs**: `fundamental_quarter` and `macro_quarter` DataFrames; `config` carrying `fundamental_schema`, `macro_schema` and `arithmetic_verification_targets`; `output_dir`; optional `run_id`; `raise_on_halt` defaults to true.
- **Process**: validates the run identifier and three configuration blocks first. Stage 1 checks the firm-quarter schema (two-way column difference, dtypes, `cusip` as text, composite-key uniqueness on `(issuer_id, fiscal_period_end)`, currency coherence, out-of-span dates) and quarantines HALT rows. Stage 2 checks macro coverage, publication lags, vintage taxonomy and positive-yield entries. Stage 3 recomputes the manuscript's declared arithmetic.
- **Outputs**: `fundamental`, `macro`, `arithmetic` (`halted`, `report_path`, `gap_register`, `aggregation_basis`, `config_version`), `artifacts` (two deviation ledgers, arithmetic report, quarantine set, macro coverage, gap register), `halted`, `run_id`, `gap_records_appended`.
- **Transformation**: raw vendor panels become schema-certified panels with row-level deviation evidence; a halted run still writes every artefact before raising `Task2HaltError`.
- **Research role**: protects the Dataset design: "We use data from original quarterly filings only, preventing look-ahead bias from subsequent restatements."
- **Equations**: currency coherence for matched currencies, and the Table 2 arithmetic that the stage reconstructs (Random Forest row: $3.2894/5=0.6579$ and $0.7490/5=0.1498$; MUFASA's average margin $6.2934/17=0.3702$):

$$
|\mathrm{fx}-1|<10^{-6},\qquad \mathrm{AllData}_m=\frac{1}{5}\sum_{k=1}^{5}\mathrm{MAPE}_{m,k},\qquad \overline{\Delta}_m=\frac{1}{5}\sum_{k=1}^{5}\left(\mathrm{MAPE}_{m,k}-\mathrm{MAPE}_{\mathrm{MUFASA},k}\right).
$$

- **Implementation distinction**: the headline "average improvement of 19.65%" is registered as not reconstructable (pooled against PySR gives 20.00%, the per-market mean 19.47%); the "27.67%" reduction against the better agentic baseline is reproduced as the mean of five per-market improvements.

### Task 3 — `run_task_3`

- **Inputs**: `config`, `index_daily`, `index_membership`, `vendor_symbols`, `conflicts_registry`, `gap_register`, `output_dir`; optional `ftse_candidate_symbols` and `run_id`.
- **Process**: certifies the index ticker registry (the four pre-verified tickers `^GSPC`, `^RUT`, `^STOXX`, `000300.SS` must be present and verified; the FTSE Asia Pacific ex-Japan placeholder is resolved by the first candidate with a non-empty close series); deduplicates membership intervals per `(issuer_id, index_name)` with the later methodology vintage winning; checks configuration consistency over the declared conflicts.
- **Outputs**: `run_id`, `index`, `membership`, `config_consistency`, `warnings`, `gap_register`, `artifacts`, `gap_records_appended`; the ticker map is a separate immutable artefact that is never overwritten with a different digest.
- **Transformation**: a raw index frame and membership history become a regime-safe verified close series and certified, non-overlapping constituent intervals; the adjusted price column never reaches regime dating.
- **Research role**: implements the Dataset and Market Settings inputs: "constituent entry and exit dates included to prevent survivorship bias" and "Regimes are computed from the index prices sourced from Yahoo Finance."
- **Equations**: after deduplication the intervals of each issuer and index are ordered and pairwise disjoint, with an open exit treated as $+\infty$:

$$
e_k\le x_k,\qquad [e_k,x_k]\cap[e_{k'},x_{k'}]=\varnothing\quad(k\ne k').
$$

- **Implementation distinction**: a forward-fill share above 0.05 warns; the sentinel exit 2099-12-31 is forbidden; an extract with no delisting and no acquisition is flagged as suspect for survivorship.

### Task 4 — `run_task_4`

- **Inputs**: validated `panel`, original-filing `raw_snapshot`, `ratio_specs` covering the ten declared ratios (P/E, P/B, P/FCF, P/OCF, EV/EBIT, EV/EBITDA, EV/FCF, EV/Sales, ROE, payout), `output_dir`; `max_failure_fraction` 0.05, `warn_threshold` 0.02, optional `run_id` and `reporting_precision`.
- **Process**: asserts the raw snapshot is preserved; applies restatement discipline; audits structural zeros against the sector registry; preserves negative free cash flow bit for bit; applies the set-missing denominator policy; evaluates Gate 0 and quarantines failing rows by a key anti-join.
- **Outputs**: cleaned `panel`, `restatement_audit_rate`, `data_quality_ledger` (structural zeros, denominators, sign fidelity), `gate0_report`, `gate0_summary`, `quarantined_rows`, audits, warnings, `gap_register`, `validation_only`, `run_id`, `artifact_paths`.
- **Transformation**: audited-restated rows are tagged `design_matrix_eligible = False` and retained for audit, never deleted; ratios are appended, never substituted for raw columns.
- **Research role**: enforces "data from original quarterly filings only" so that later restatements cannot leak backward.
- **Gate 0 and the denominator rule**, per row, with a check halting only when its failure fraction over evaluable rows exceeds 0.05:

$$
|A-(L+E)|\le\max\left(10^{-3}|A|,\tfrac{1}{2}\mathrm{precision}\right),\qquad \frac{|MC-P\cdot S|}{MC}\le0.02,\qquad \tau_{\mathrm{target}}>\tau_{\mathrm{filing}},\qquad \mathrm{ratio}=\begin{cases}N/D,&D>0\\ \mathrm{missing},&\text{otherwise.}\end{cases}
$$

- **Implementation distinction**: the target date must also equal the next fiscal quarter end, and the split-adjustment reference date must not precede the period end. An imputed structural zero halts; the weak pending-restatement flag never excludes a row.

### Task 5 — `run_task_5`

- **Inputs**: cleaned `panel`, deduplicated `membership`; keyword `config` (required `index_to_market`, optional `nominal_constituents`, `rejection_warn_threshold` 0.01, `coverage_tolerance` 0.05), `output_dir`, `run_id`, optional `expected_coverage`.
- **Process**: maps each fiscal period to the calendar quarter holding the majority of its days; applies the filing-date gate; applies the inclusive membership gate; adds the single combined admission column `eligible_for_design_matrix`.
- **Outputs**: `panel` sorted on `(issuer_id, fiscal_period_end)`, `divergences`, `rejection_log`, `coverage`, `membership_rejected`, `row_counts`, `warnings`, `run_id`, `artifacts`.
- **Transformation**: fiscal-labelled rows become point-in-time rows. A row is admitted only when its original filing precedes the target date, and only while the firm is a genuine constituent.
- **Research role**: implements "define the target variable as the stock price at the end of the fiscal quarter immediately following each filing period" without look-ahead, and survivorship control through constituent intervals.
- **Equations**: with period $[\sigma_{i,t},e_{i,t}]$, original filing date $f_{i,t}$, target date $\tau_{i,t}$ and Task 4's flag $\mathrm{dme}_{i,t}$:

$$
q^{\mathrm{cal}}_{i,t}=\arg\max_{q}\bigl|[\sigma_{i,t},e_{i,t}]\cap q\bigr|,\qquad \mathrm{eligible}_{i,t}=\mathbf{1}\lbrace f_{i,t}<\tau_{i,t}\rbrace\,\mathbf{1}\lbrace\mathrm{entry}_i\le e_{i,t}\le\mathrm{exit}_i\rbrace\,\mathrm{dme}_{i,t}.
$$

- **Implementation distinction**: an assigned-quarter overlap share below 0.6 is registered as divergent; fiscal-year-change rows keep a missing mapping; a market with no constituent hit halts after its coverage table is written.

### Task 6 — `run_task_6`

- **Inputs**: `panel`, `classifications` (GICS vintages), `index_daily`; keyword `output_dir`, `min_cell_occupancy` 200, optional `occupancy_mask`, `run_id`, `split_boundaries`; `regime_timeline` defaults to `causal`.
- **Process**: attaches the paper sector label and as-of GICS code through a backward as-of join on the effective date; dates daily bull and bear states from the verified closes; aggregates them to calendar quarters; builds the context key; audits training occupancy with a sector-pooled fallback.
- **Outputs**: keyed `panel`, `regime_daily`, `regime_quarterly`, `regime_quarterly_ex_post`, `regime_switches`, `cell_occupancy`, `timeline_sha256`, `pooling_map`, `occupancy_status`, warnings and register paths.
- **Transformation**: index prices and classification history become the context variable $C(i,t)=(s(i),r(t))$, rendered as `sector|regime`; occupancy is deferred, and registered, when no training mask exists yet.
- **Research role**: "a bull market is declared when the index has risen at least 20% from its most recent trough, and a bear market when it has fallen at least 20% from its most recent peak."
- **Equations**: the causal daily state machine, with $\underline{P}_d$ and $\overline{P}_d$ the most recent trough and peak; the quarterly label is the majority of trading days, ties going to the last trading day:

$$
r_d=\begin{cases}\mathrm{Bull},&P_d\ge1.2\,\underline{P}_d\\ \mathrm{Bear},&P_d\le0.8\,\overline{P}_d\\ r_{d-1},&\text{otherwise.}\end{cases}
$$

- **Implementation distinction**: a day satisfying both bands is labelled bull, the pre-first-breach span is back-filled, and the ex-post variant replaces the peak side only; each resolution is a registered gap decision. A context below 200 training firm-quarters takes the key `sector|POOLED`.

### Task 7 — `run_task_7`

- **Inputs**: `panel`, `output_dir`; keyword `feature_columns`, `market_column`, `train_fraction` 0.8, `embargo_quarters` 1, `fit_fraction` 0.9, `coverage_threshold` 0.8, `gap_threshold_days` 135, optional `codebook`, `retrieval_index`, `regime_timeline` snapshots, `run_id`, `eligibility_column`.
- **Process**: filters on Task 5's combined eligibility flag; builds the forward-shifted target within issuer on the calendar-quarter axis; splits each market chronologically; purges training rows whose target date reaches the test window; carves fitting and validation sub-partitions; freezes the fitting statistics and snapshots behind a SHA-256 token.
- **Outputs**: `panel` with `partition` and `sub_partition`, `split_artefact`, `freeze_manifest`, `frozen_document`, `freeze_token`, `counts`, `exclusions`, `warnings`, `run_id`, `gap_records_appended`, `artifacts`.
- **Transformation**: eligible firm-quarters become a target-carrying, leakage-safe train/embargo/test panel and an immutable frozen-parameters document that later stages must verify rather than re-estimate.
- **Research role**: "the first 80% of quarters form the training set and the remaining 20% form the held-out test set."
- **Equations**: with $n_m$ distinct calendar quarters in market $m$, quarters ordered chronologically:

$$
y_{i,t+1}=P_i\bigl(e_{i,t+1}\bigr)\ \text{if } e_{i,t+1}-e_{i,t}\le135\text{ days},\qquad \mathcal{Q}^{\mathrm{train}}_m=\lbrace q_1,\ldots,q_{\lfloor0.8n_m\rfloor}\rbrace,\qquad n^{\mathrm{fit}}=\max\left(1,\lfloor0.9\,n^{\mathrm{train}}_m\rfloor\right).
$$

- **Implementation distinction**: one embargo quarter and the row-level purge are leakage counters beyond the paper's 80/20 sentence; fewer than 12 test quarters warns. Frozen statistics are the fitting-block mean, population SD, 1st/99th percentiles and coverage.

### Task 8 — `run_task_8`

- **Inputs**: `config` (codebook schema, variable vocabulary, training window, optional `min_denominator_tolerance`), `panel`, `output_dir`; keyword `run_id`, `partition_column` (`partition`).
- **Process**: builds the per-share variables, then the firm-level multiples, then the codebook with both frames handed to it; produces the modelling ratios ROE and Payout under the same admissibility helper; writes the codebook (JSON and JSONL, both digested), registries, denominator policy and vendor-EPS divergence evidence.
- **Outputs**: `codebook`, `per_share`, `multiples`, `sha256`, final `panel`, `run_id`, `tolerance`, `ratio_quality_counts`, `gap_records_appended`, `artifacts`.
- **Transformation**: trailing-twelve-month totals become per-share and multiple features, each with a per-row quality code, and a hashed codebook of symbols, machine names, definitions, units and training coverage.
- **Research role**: supplies the variables of Table 4's equations, for example $NI_{\mathrm{ps}}$, $FCF_{\mathrm{ps}}$, $BVPS$, $PE$, $PB$, $P/FCF$ and $EV/EBITDA$.
- **Equations**: with period-end shares $S$, admissible when finite, positive and not below the tolerance (default $10^{-6}$):

$$
x_{\mathrm{ps}}=\frac{X_{\mathrm{TTM}}}{S},\qquad TBVPS=\frac{E-GW-INT}{S},\qquad EV=MC+D-\mathrm{Cash},\qquad PE=\frac{MC}{NI},\qquad ROE=\frac{NI}{E},\qquad \mathrm{Payout}=\frac{\mathrm{Div}}{NI}.
$$

- **Implementation distinction**: `EPS_TTM` is copied from the vendor rather than recomputed, with its divergence recorded; ratios with non-positive or below-tolerance denominators are set missing, never clipped. Task 4's ratio columns are the audit copy; ROE and Payout here are the modelling set.

### Task 9 — `run_task_9`

- **Inputs**: `panel`; keyword `feature_columns`, `winsor_bounds` or `frozen_document` (exactly one), required `freeze_token`, `min_firms_per_quarter`, `min_firms_per_sector_quarter`, `output_dir`, optional `market_column`, `dispersion_feature` (`EV_EBIT`).
- **Process**: verifies the freeze token, resolves one set of bounds, and hands the same bounds, digest and market column to the market, sector and dispersion stages; joins the aggregates back onto the firm rows in input order.
- **Outputs**: `market`, `sector`, `dispersion`, joined `panel`, `warnings`, `artifact_paths`, `bounds_digest`, `winsor_bounds`, `aggregate_columns`.
- **Transformation**: in-index firm features become contemporaneous market and sector anchors over one population under one frozen fit, so relative-valuation inputs use only the same quarter.
- **Research role**: supplies aggregate terms such as $PB_{\mathrm{mkt,med}}$ in PySR's Table 4 expression and $(P/FCF)_{\mathrm{mkt}}$ in the Growth agent's equation.
- **Equations**: clipping to the frozen bounds, then per (market, quarter) the median, mean and sample SD, and the within-cell dispersion over at least two observations:

$$
\tilde x=\min\bigl(\max(x,q_{01}),q_{99}\bigr),\qquad s_{m,t}=\sqrt{\frac{1}{n-1}\sum_{i}(\tilde x_i-\bar{\tilde x})^2},\qquad \sigma^{EV/EBIT}_{m,s,t}=s\bigl(\tilde x\mid m,s,t\bigr).
$$

- **Implementation distinction**: sector cells publish medians only. A thin cell keeps its row and count while its median is withheld, and the floors are caller-supplied (the task list declares 50 firms per quarter and 5 per sector-quarter).

### Task 10 — `run_task_10`

- **Inputs**: `panel` from Tasks 5–9; keyword `input_columns` overrides, `market_median_column` (`market_Revenue_ps_median`), `dividend_sign_convention` (`positive_amount_paid`).
- **Process**: resolves working columns from declared spellings and converts Task 8's fractional ROE once to `ROE_pct`; builds label-anchored lags at horizons 1, 4 and 8; computes growth rates, payout and sustainable growth; builds the engineered flags.
- **Outputs**: engineered `panel`, `warnings`, `lag_missing_counts`, `family_map`, `input_sources`.
- **Transformation**: point-in-time levels become lagged, growth and discretised features keyed to the chronological ordinal $4\cdot\mathrm{year}+\mathrm{quarter}-1$, so a lag is the value exactly $k$ fiscal quarters earlier.
- **Research role**: supplies growth terms such as $g_{EPS}$, which the released Earnings equation uses in percent: $NI_{\mathrm{ps}}\cdot(1+0.01\cdot g_{EPS})\cdot PE\cdot0.88$.
- **Equations**: growth in percent on the absolute prior-year denominator, payout and sustainable growth:

$$
g_{x,t}=100\,\frac{x_t-x_{t-4}}{|x_{t-4}|},\qquad \mathrm{Payout}_t=\frac{\mathrm{Div}_t}{NI_t},\qquad \mathrm{SustGrowth}_t=\mathrm{ROE}^{\%}_t\,(1-\mathrm{Payout}_t).
$$

- **Implementation distinction**: growth is set missing on a zero prior year or a sign flip; payout is missing for non-positive net income. The negative-cash-flow factor takes levels 0, 1, 2 at the boundaries 0 and −1000, and a missing flow stays missing. A lag-quality mean below 0.7 warns.

### Task 11 — `run_task_11`

- **Inputs**: Task 8 `codebook`, curated `queries`; keyword `output_dir`, `run_id`, optional `embed_fn`, `model_name` (`all-MiniLM-L6-v2`), `model_revision`, `top_k` 20, `sensitivity_depths` (5, 10, 20), `coverage_threshold` 0.8, `pass_threshold` 0.9, `report_path`.
- **Process**: turns each codebook entry into a descriptor over symbol, machine name, definition and units; encodes them to unit vectors; builds an exact cosine index; binds a retriever to that index, depth and threshold; runs the pre-flight at the primary and every sensitivity depth.
- **Outputs**: `bundle`, `retrieve_fn` (consumed by Task 15), `embedding_model_hash`, `index_digest`, `var_ids`, `n_indexed`, `preflight`, `preflight_by_depth`, `primary_depth`, `report_path`, `artifacts`, `gap_records_appended`, `run_id`.
- **Transformation**: a variable dictionary becomes a searchable semantic index and a bound tool that returns ranked variables with a coverage verdict rather than an exception.
- **Research role**: "the agent first queries a semantic retrieval mechanism to obtain candidate variable names and descriptions … If a retrieval attempt fails (e.g., due to unavailability or insufficient coverage), the model receives structured feedback."
- **Equations**: cosine similarity, coverage over the retrieved set $\mathcal{R}_k(q)$ (at most $k$ identifiers, never padded; a missing coverage counts as 0), and the pre-flight pass rate over at least 50 queries:

$$
\mathrm{sim}(q,v)=\frac{e_q^\top e_v}{\lVert e_q\rVert\,\lVert e_v\rVert},\qquad \mathrm{cov}(q)=\frac{1}{|\mathcal{R}_k(q)|}\sum_{v\in\mathcal{R}_k(q)}c_v<0.8\Rightarrow\mathtt{COVERAGE\_BELOW\_THRESHOLD},\qquad \frac{n_{\mathrm{pass}}}{n_{\mathrm{queries}}}\ge0.9.
$$

- **Implementation distinction**: the exact in-memory search substitutes for the approximate stores the task list names (faiss, hnswlib), registered as a gap decision; only the primary depth can halt, and only after every artefact is written.

### Task 12 — `run_task_12`

- **Inputs**: `model_revision`; keyword `model_id`, `run_id`, optional `container`, `dry_run` (default true), `scratch_dir`, `engine_factory`, `transport`, `per_role_seconds`, `n_iterations` 1, workers (5 specialist, 1 meta, 1 distiller), `max_new_tokens` 8192, `dtype`, `seed` 0, `smoke_prompt`, `clock`.
- **Process**: pins the engine configuration; launches one server for seven role keys, applying the out-of-memory back-off once (factor 0.5, floor 1); asserts the engine-reported window against the pin; issues one smoke request per sampling profile and checks for truncation; builds and probes one callable per role; measures and evaluates the wall clock against the budget.
- **Outputs**: `model_revision`, `container`, `config`, `handles`, `registry`, `scheduler`, `wall_clock`, `budget`, `smoke`, `artifacts`, `role_callables`, `model_id`, `run_id`, `dry_run`, `backoff_applied`, `probe_calls`, `register_entries`.
- **Transformation**: a pinned checkpoint becomes role-isolated sampling callables, so one role's parameters cannot leak into another. A dry run constructs nothing and only projects the wall clock.
- **Research role**: "We use Qwen3-4B-Thinking … for all agents, with a temperature of 0.7 for the agents and 0.3 for the memory components"; the 600-second baseline mirrors "∼10 mins per agent".
- **Equations**: sampling per role, and the wall-clock warning rule:

$$
\tilde f^{(a)}\sim\pi_\theta\bigl(\cdot\mid p^{(a)};\,T=0.7\bigr),\qquad \mathbf{Z}\sim\pi_\theta\bigl(\cdot\mid p^{\mathrm{distil}};\,T=0.3\bigr),\qquad \mathrm{warn}\iff t_{\mathrm{role}}>3\times600\ \mathrm{s}.
$$

- **Generation cap and seed**: the orchestrator's own defaults are 8,192 tokens and seed 0, so Task 22's serving stage passes `max_new_tokens=16384` (the paper's cap) and the registry's `vllm_sampler` seed for its single call (call index 0, the first plan seed); all replications share that one engine and sampler seed. Top-p 0.95, top-k 0 and repetition penalty 1.0 come from the study configuration as gap decisions.

### Task 13 — `run_task_13`

- **Inputs**: `perspective_agents`, `learnings_by_perspective`, `error_feedback_by_perspective`, `meta_contexts`, `agent_losses_by_context`, `incumbent_weights_by_context`, `meta_learnings`, `memory_records_by_perspective`, `tokenizer`, `output_dir`, `iteration`, `seed`; keyword `operator_whitelist`, `admissible_variables`, optional `agent_order`, `templates`, `distillation_priority` (`best_first`).
- **Process**: assembles every specialist prompt, every context's meta-coordinator prompt and every distillation prompt of one iteration through three bound assemblers; counts each block with the server tokenizer as sent; truncates only the learnings block, by whole tail blocks; merges the prompt-hash registry and token log key by key.
- **Outputs**: `specialist_prompts`, `meta_prompts` (keyed by context), `distillation_prompts`, `prompt_hashes`, `registry_path`, `token_log_path`, `n_registry_keys`, `assemblers` (`specialist`, `meta`, `distiller`) reused by Tasks 15, 19 and 20.
- **Transformation**: philosophies, incumbents, learnings and structured errors become budget-certified prompts keyed by role, perspective or context, iteration and seed.
- **Research role**: realises Algorithm 1's $p^{(a)}\leftarrow(a,\tilde f^{(a)},\mathbf{Z}^{(a)})$, its error-feedback union, and Algorithm 2's $p^{\mathrm{meta}}\leftarrow(C(i,t),\mathcal{L}^{(a)},\tilde{\mathbf{w}}_{C(i,t)},\mathbf{Z}^{\mathrm{meta}})$.
- **Equations**: per-block token budgets with the 884-token slack, and the meta and distillation budgets:

$$
n_{\mathrm{phil}}\le1500,\ n_{\mathrm{prior}}\le3000,\ n_{\mathrm{learn}}\le8000,\ n_{\mathrm{err}}\le3000,\qquad 15500+884=16384,\qquad 200+400+200+4000=4800.
$$

- **Implementation distinction**: the distillation prompt follows Appendix E's eight blocks (Summary, Key Insights, Statistical Diagnostics, What Works, What Fails, Important Variables, Agent Adaptation Behavior, Design Principle) and drops schema tail blocks around the mandatory Summary and Key Insights core. Any budget breach raises `Task13PromptBudgetExceededError`.

### Task 14 — `run_task_14`

- **Inputs**: `candidates` (expression strings), `grammar_spec`, training `panel`, `iteration`, `output_dir`.
- **Process**: builds the grammar once (anchor whitelist, declared variables, precedence tiers, bounds, version hash); parses each candidate by precedence into a canonical S-expression; validates names, bounds, logarithm and exponential domains, coverage and finiteness in priority order; encodes one structured error per rejection; writes the error ledger.
- **Outputs**: `grammar`, `results` (tree and statistics, or a structured rejection with quantitative evidence), `n_ok`, `n_rejected`.
- **Transformation**: free-text model output becomes either a validated, hashable expression tree or a machine-parseable error object (taxonomy code, action class, candidate hash, iteration); a bad candidate never raises.
- **Research role**: "if the expression fails to execute (e.g., due to syntax errors, invalid operations, or non-finite outputs), the system returns structured feedback … which is incorporated into the prompt $p^{(a)}$."
- **Equations**: over the eleven-token surface `+ - * / ^ log exp abs < > ind`, the bounds and the logarithm domain rule (a logarithm is rejected only if a finite argument is not strictly positive):

$$
\mathrm{depth}(T)\le8,\qquad \#\mathrm{ops}(T)\le30,\qquad \#\mathrm{vars}(T)\le12,\qquad \min_{r:\,u_r\ \mathrm{finite}}u_r>0\ \ \text{for each}\ \log u.
$$

- **Inputs**: Task 15's long `predictions` frame, `output_dir`; keyword `perspectives`, `min_firm_quarters` 200, `solver_config`, `n_starts` 8, `seed`, optional `task_20_weights` and `released_matrix`, `run_id`, optional `coordinator_proposals` (Task 20's proposals keyed `market::unit` or by a market-free unit key).

- **Research role**: "computes their weight vector … via SLSQP-based constrained optimization"; Appendix D reports the learnt weights over Earnings, Cash Flow, Asset, Growth and Quality by sector and regime.
- **Equations**: the constrained objective per cell $c$, solved with feasibility tolerance $10^{-8}$, optimality tolerance $10^{-10}$ and 500 iterations:

$$
\hat{\mathbf{w}}_c=\arg\min_{\mathbf{w}}\ \frac{1}{|R_c|}\sum_{r\in R_c}\frac{|\mathbf{w}^\top\hat{\mathbf{y}}_r-y_r|}{|y_r|}\quad\text{s.t.}\quad w_a\ge0\ (a\in A^*),\ \ w_a=0\ (a\notin A^*),\ \ \sum_{a\in A^*}w_a=1,\qquad \mathbf{w}^{(\mathrm{start})}=\tilde{\mathbf{w}}^{(0)}\big|_{A^*}\big/\mathbf{1}^\top\tilde{\mathbf{w}}^{(0)}\big|_{A^*}.
$$

- **Implementation distinction**: every start runs to completion. The lowest-objective candidate is chosen, a converged one preferred on a tie; it is projected into the simplex and re-scored. Each start's convergence flag and solver message are recorded in `per_start`, each fit reports `n_converged`, `chosen_converged` and `premature_termination`, and units whose chosen start did not converge are listed in `non_converged_units` with a warning. The call halts only when no start is feasible, and the halt message counts the starts with a non-finite objective, with an equality violation beyond the tolerance and with a negative entry beyond the tolerance. The fit over $A^*$ lives in the $k^*=|A^*|$ coordinates of the subset and is embedded back with exact zeros outside it; each fit reports its `support` and `initial_point_source` (`coordinator_proposal` or `uniform`). A proposal selecting fewer than two active perspectives is not a valid selection: its unit is fitted over every active perspective from the uniform start and listed in `proposal_support_too_small`. With no proposals the start list is exactly the uniform point and the same Dirichlet draws as before.

$$
L=\left\lfloor4\left(\frac{T}{100}\right)^{2/9}\right\rfloor,\qquad \hat\sigma^2_{\mathrm{LR}}=\hat\gamma_0+2\sum_{k=1}^{L}\left(1-\frac{k}{L+1}\right)\hat\gamma_k,\qquad DM=\frac{\bar d}{\sqrt{\hat\sigma^2_{\mathrm{LR}}/T}},\qquad DM^{\ast}=DM\sqrt{\frac{T+1-2h+h(h-1)/T}{T}}.
$$

- **Implementation distinction**: two-way clustering, $V=V_{\mathrm{firm}}+V_{\mathrm{quarter}}-V_{\cap}$ (the quarter term itself Newey–West), and Benjamini–Hochberg control are additions beyond Appendix B's two corrections; the clustered view is stated as primary. Defaults are $\alpha=0.05$ and $h=1$.

b_j=\mathbf{1}\bigl\lbrace\mathrm{MAPE}_j<\mathrm{median}_{\mathbf{M}}(\mathrm{MAPE})\bigr\rbrace,\qquad \hat y^{(\mathrm{strat})}_{i,t+1}=\mathbf{w}_{\mathrm{strat}}^\top\hat{\mathbf{y}}_{i,t+1}.
